# 안면 비대칭 진단 모니터링 시스템

## 1. 프로젝트 개요
본 시스템은 웹캠을 통해 사용자의 안면 랜드마크를 실시간으로 추적하고, 지정된 4가지 표정 변형에 따른 안면 대칭성을 분석하는 진단 보조 프로그램입니다. 형태학적 수치 해석 알고리즘을 활용하여 안면 비대칭 및 마비 증상의 종합 위험도를 정량적으로 모니터링하고 시각화합니다. 초기 기획 단계에서 데이터 구조를 체계화하기 위해 개체 관계도를 설계하였으며, 제한된 일정 내에 안정적으로 동작하는 최소 기능 제품 구현 프로세스를 바탕으로 개발되었습니다.

## 2. 핵심 기능 및 기술적 주안점
* 형태학적 수치 해석 기반 데이터 정규화: 카메라와 사용자 간의 거리 변화 및 개인별 골격 크기 차이로 인한 정량화 오차를 해결하기 위해 절대적 픽셀 거리가 아닌 상대적 비율과 각도를 연산 알고리즘에 도입했습니다. 미간과 입술의 틀어짐은 벡터 내적을 통한 수직각으로, 눈썹과 광대 간의 거리는 좌우 대칭 비율로 변환하여 환경 종속성을 제거한 객관적인 위험도 점수를 산출합니다.
* 멀티스레딩 기반 비동기 입출력 제어: 실시간 프레임 스캔 루프 내부에서 음성 안내 멘트가 동기 방식으로 실행될 때 발생하는 화면 멈춤 문제를 해결하기 위해 멀티스레딩 구조를 적용했습니다. 오디오 출력 로직을 별도 스레드로 분리하고 전역 플래그 변수를 통해 스레드 간 상태를 공유함으로써 프레임 드롭을 방지하고 중단 없는 모니터링 환경을 유지합니다.
* 공간적 유효성 검증을 통한 데이터 품질 통제: 사용자의 부적절한 자세나 프레임 이탈로 인해 무효한 랜드마크 데이터가 수집되는 것을 방지하기 위해 실시간 공간 유효성 검사 로직을 포함했습니다. 얼굴 최외곽의 핵심 좌표들이 화면에 설정된 타원형 가이드라인 영역 내에 위치하는지 실시간으로 판단하며, 범위를 벗어날 경우 상태 머신을 초기화하고 경고 음성을 송출하도록 통제 환경을 구축했습니다.

## 3. 시스템 동작 로직
본 시스템은 연속적인 프레임 공급과 상태 전환에 따라 파이프라인이 제어됩니다. 전체적인 스크립트 간 통신 및 연산 순서는 다음과 같습니다.

1. 초기화 및 가이드 정렬: `main.py`가 실행되면 카메라 장치와 가상환경 내 패키지를 로드하고 타원형 가이드라인을 화면에 렌더링합니다. 초기 정렬 안내 음성이 비동기로 송출됩니다.
2. 실시간 프레임 스캔 및 유효성 검증: 웹캠으로부터 이미지 프레임을 수신하여 입력 데이터를 스캔합니다. 추출된 안면 랜드마크 좌표가 가이드라인 내부 경계 조건에 부합하는지 검증합니다.
3. 상태 머신 기반 시나리오 제어: 유효성 검증이 통과되면 현재 진행 단계에 해당하는 표정 유도 안내를 수행합니다. 전역 플래그를 통해 안내 음성 송출이 완료되었음이 확인되면 3초 카운트다운 타이머를 기동합니다.
4. 특징점 추출 및 모듈 간 통신: 타이머가 만료되는 시점에 해당 표정 프레임을 캡처하여 로컬에 저장하고, 안면 핵심 좌표 배열을 `metrics_calc.py`의 특징점 추출 함수로 전달합니다.
5. 정량적 분석 및 리포트 산출: 4가지 표정 시나리오가 모두 완료되면 `metrics_calc.py` 내부의 종합 리포트 계산 함수가 호출됩니다. 7가지 대칭성 지표의 점수를 환산하고 가중 평균을 적용하여 종합 위험도 점수 및 판정 등급을 산출한 후 결과 화면을 모니터링 창에 시각화합니다.

## 4. 프로젝트 폴더 구조
```text
Project_Root/
├── .gitignore
├── README.md
├── requirements.txt
├── main.py
├── metrics_calc.py
├── test_tts.py
├── captured_images/
│   ├── 0_resting.jpg
│   ├── 1_closed.jpg
│   ├── 2_raised.jpg
│   └── 3_smile.jpg
└── venv/
```
main.py: 비동기 음성 안내 스레드 제어, 타원형 가이드라인 좌표 검증, 카운트다운 및 촬영 시나리오 상태 머신 관리 등 프로그램의 메인 루프를 담당합니다.

metrics_calc.py: 유클리드 거리 및 벡터 내적 각도 연산, 대칭 비율 정규화 공식 적용, 위험도 점수 및 판정 등급 리포팅 알고리즘을 담당합니다.

test_tts.py: 로컬 오디오 엔진의 호환성 및 한국어 음성 자산 정상 로드 여부를 검증하기 위한 단독 실행 테스트 파일입니다.

requirements.txt: 프로그램 구동에 필요한 외부 라이브러리의 의존성 명세 파일입니다.
